# Reference artwork

Category illustrations, promotional banners and the orange avatar are extracted from the screenshots supplied by the user for this UI reproduction. `tool/extract_reference_assets.ps1` records the source regions. Text, navigation, cards, profile fields and menu rows are native Flutter widgets, not screenshots.

The crops retain the resolution and compression of the supplied images. Replace them with the original brand artwork for higher-resolution production assets. The pictured profile data is static reference/demo content, not data obtained from Google.
