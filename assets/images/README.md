# Recursos visuales de Cibermax

Las seis ilustraciones PNG de products/ son dibujos originales creados para esta demostración, sin fotografías, marcas ni recursos de terceros. Pueden utilizarse y modificarse en este proyecto sin atribución externa.

Se pueden regenerar en Windows con PowerShell:

    ./tool/generate_product_art.ps1

Representan productos ficticios; no son fotografías de artículos comerciales. El catálogo, las especificaciones, las valoraciones y los precios también son de demostración.
