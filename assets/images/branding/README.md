# Logo CIBER-MAX

`ciber_max_logo.jpg` es la imagen original proporcionada por el usuario (2816 × 1536), conservada sin redibujar el logo ni cambiar sus colores.

Las versiones PNG de Android e iOS derivan de este mismo archivo mediante escalado proporcional. El recurso cuadrado de Android 12 incorpora márgenes para mantener el contenido dentro de la máscara del sistema.

La propiedad y los permisos de marca corresponden al titular del logo.
